# Three natures of a location

Agent-maintained docs rot when a location's nature is ambiguous: done items pile up in a plan treated as an archive, a view is hand-edited to paper over a gap, a trace gets purged as if it were a to-do. Resolve before writing anywhere: **work plan** (empties — a remaining item = work not done; a resolved one disappears, kept or discarded), **archive** (never empties), **inventory** (a view mirroring an archive — *reconciled*, never emptied or frozen; a discrepancy = work on the archive, never an edit to the view). State the nature in the location's own header ("this empties") so every future agent inherits the decision instead of re-guessing it.
