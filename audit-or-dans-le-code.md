## B. Candidats moyens — enrichissements ponctuels

- **`task_id` de spawn = label, jamais une vérité** — l'orchestrateur peek pour choisir le *prompt de rôle*, mais l'agent claime lui-même et peut tenir une autre tâche (course entre slots) ; toute la récup est indexée `owner==short`. Sets `inflight` en mémoire pour éviter le double-spawn sans muter le CSV. (`consolidation-pipeline/orchestrate.py:244-253,327-349`) **→ pattern `slots-vs-budget` ou `layered-watchdog`.**
- **Récup d'orphelin AVANT le fingerprint de stall** — sinon une récup réussie compte comme tour « blanc » et peut déclencher le drain à tort. Champs exacts de l'empreinte : `(id, status, owner, note)`. (`consolidation-pipeline/orchestrate.py:380-395,189-196`) **→ pattern `slots-vs-budget`.**
- **Stall extraction ≠ fingerprint** — variante : 5 agents consécutifs sortis avec 0 commit filtré par leur short + prédicat de queue volontairement approximatif (« heuristique cheap + filet exact », pas de duplication de la logique de claim). (`extraction-pipeline/orchestrate.py:687-718,1066-1088`) **→ pattern `slots-vs-budget` (nuance).**
- **`owner` = sémaphore de passe de validation** — claim d'une passe : `owner=<short>` sans changer `status` ; 1er ok → owner **vidé** pour libérer la place du 2e valideur ; sélection exclut owner non vide. Un champ fait sous-machine-à-états. (`consolidation-pipeline/task.py:410,562-564,291-292`) **→ pattern `nn-validation`.**
- **Pièges de la machine à états d'orphelins** — reset d'un enfant validate : status **reste** `to_validate` (le passer `todo` le gèlerait — `is_validatable` exige `to_validate`) ; rc dédié `3` = no-op distinct de récup/échec sans parser stdout ; verbe `clear-lease` pour la lease fantôme (short sans enfant vivant, hors d'atteinte du force-release) ; chemins admin best-effort (une récup ne doit jamais faire planter le run qu'elle répare) et `git checkout` de la version *committée* (le working-tree d'un correcteur mort est du poison). (`consolidation-pipeline/task.py:717-816`) **→ pattern `layered-watchdog` ou `correction-lease`.**
- **Rollup parent anti-TOCTOU** — au 2e ok : enfant→done ET test « tous frères done → parent done » dans la même section critique. (`consolidation-pipeline/task.py:543-561`) **→ pattern `nn-validation`.**
- **Fail-closed sur garde historique** — la garde « validateur ≠ composeur » greppe l'historique ; **aucun** commit composeur trouvé → refus du claim (un historique cassé bloque au lieu d'ouvrir un trou dans le N/N). (`extraction-pipeline/claim.py:72-96,185-198`) **→ pattern `nn-validation`.**
- **Tokens réservés du log** — deux sous-chaînes contrat machine (« spawn », marqueur terminal) → contraintes en cascade : bandeau non horodaté (commande Monitor collable), séparateur de reprise qui évite les tokens, `strip_ts` pour rendre l'event brut aux parsers. Discipline « log lisible humain ET parsé machine ». (`consolidation-pipeline/orchestrate.py:546-599,515-517`) **→ pattern `banner-as-monitor`.**
- **Horodatage à la seconde pour tri lexicographique + migration safe par direction** — le prédicat stale compare des *strings* ISO ; une vieille valeur date-seule est un préfixe plus court → trie avant → les faux positifs tombent du côté bénin (re-valider trop, jamais trop peu). « Migration sans migration ». (`consolidation-pipeline/_store.py:146-154`) **→ pattern `tabular-registry`.**
- **Sharding du gate fidélité par buckets de citations** — comptage par source, empilage glouton déterministe ≤ cap, source sur-citée = bucket-atome jamais coupé ; cap calibré sur le budget temps du valideur ; `done` refuse un reduce à 0 bucket (0 shard = validation gratuite). (`consolidation-pipeline/task.py:242-272,519-521,57-60`) **→ pattern `sourcing-fidelity-gates`.**
- **peek/claim partagent les helpers de sélection** — `peek_next` prédit exactement ce que `claim_next` prendrait, par construction, pas par duplication ; peek sans flock. (`consolidation-pipeline/task.py:357-386,424`) **→ pattern `script-picks-task`.**
- **Verbe claim polymorphe** — un seul `claim <slug>` : l'état de la ligne décide du rôle (rédaction vs validation) et le script **annonce** le rôle — l'agent l'apprend du output, il ne le choisit pas. (`report-task.py:107-118,164-168`) **→ pattern `script-picks-task`.**
- **Sentinelle « aucun thème » obligatoire** — un map qui ne trouve rien doit le *dire* (`<!-- aucun thème -->`) ; distingue « rien trouvé » (valide) de « travail non fait » (refusé). (`consolidation-pipeline/check.py:36,159-174`) **→ pattern `sourcing-fidelity-gates`.**
- **Région générée d'un pipeline = API d'entrée de l'autre** — la consolidation parse le bloc `INVENTORY:BEGIN/END` maintenu par l'inventory d'extraction, filtré `Validate == 2/2`. (`consolidation-pipeline/inventory.py:76-100`) **→ pattern `generated-regions`.**
- **Tests : les 4 lignes non évidentes** — `commit.gpgsign false` dans la fixture (sinon hang pinentry sur machine à signing global) ; `session_env` monkeypatch l'env var et **retourne le short** à grepper ; fixture `git_log` (sujets de commit) comme oracle des transitions ; course réelle non synchronisée + assertion `sorted([rc1,rc2]) == [0, ≠0]` + les **deux** stderr dans le message d'échec. (`patterns/blackbox-test-discipline/tests/conftest.py:37-55,47,143-172` ; `patterns/blackbox-test-discipline/tests/test_concurrency.py:42-66`) **→ pattern `blackbox-test-discipline`.**
- **Allowlist dupliquée en prose dans le prompt worker** — l'agent sait d'avance ce qui est interdit → pas de patinage sur refus silencieux ; commentaire « garder les deux en sync ». (`extraction-pipeline/orchestrate.py:160-178,721-760`) **→ pattern `prompts-as-files` ou `headless-preamble`.**
- **watch.py : relecture complète + marqueur en dernière ligne** — pas de tail -f ni seek : relit tout, émet `lines[emitted:]` (immune aux truncate) ; exit seulement si le marqueur est la **dernière** ligne ; méta sur stderr, stdout = flux pur. Reprise d'un run : append avec séparateur, jamais d'écrasement ; le marqueur terminal tombe « quoi qu'il arrive » (RUN.md best-effort). (`consolidation-pipeline/watch.py:52-92` ; `orchestrate.py:871-891,1131-1199`) **→ pattern `banner-as-monitor`.**
- **`re.sub` avec lambda en replacement** — le contenu injecté dans une région générée passe par `lambda _m: new_inv` : un `\g<…>` dans le tableau généré ne sera jamais interprété par le moteur regex. Bug classique et silencieux. (`extraction-pipeline/inventory.py:195-204`) **→ pattern `generated-regions`.**
- **Heartbeat dormant par env var** — chemin passé via `ORCHESTRATE_HEARTBEAT`, sliding = inactivité sur `max(mtime log, mtime heartbeat)` ; canal pour qu'un script long prouve sa vie quand le JSONL ne bouge pas. Câblé sans consommateur actuel. (`extraction-pipeline/orchestrate.py:461-470,1007-1020`) **→ pattern `layered-watchdog`, ou écarter (dormant).**
